# Building Hardware

The `hardware` repository publishes its own documentation site, which carries
the board designs, the fabrication and assembly procedures, and the mechanical
designs. Start there.

[Hardware documentation](https://tag-designs.github.io/hardware/){ .md-button .md-button--primary }

## Tools

For PCB design we use [kicad](https://www.kicad.org/) and to automate the generation of gerber and outline files we use [kibot](https://github.com/INTI-CMNB/KiBot).

For designing 3D base board adapters we use [openscad](https://openscad.org/)
