# Visualization

Data downloaded from a tag is inspected with the **Bit Tag Visualizer**, a
desktop application that plots activity, temperature and voltage over the life
of an experiment.

The visualizer loads a downloaded data file and draws activity as a percentage
over time, with temperature and voltage available as overlays. From there it
supports zooming and scrolling to a window of interest, cursors for reading
values off the plot, low-pass filtering to smooth activity traces, and
actograms with an optional sun-elevation overlay for comparing behaviour
against day length. Plots and selected data can be exported for use elsewhere.

[Bit Tag Visualizer reference](https://tag-designs.github.io/software/user/apps/btdataviz.html){ .md-button }

The step-by-step guide is in the software documentation.
