# Tag Assembly

Assembling a finished tag is the step after the boards come back from
fabrication: fitting the components the assembly house does not place, mounting
the board in its printed case, attaching the harness, and checking the result
before the tag goes anywhere near a bird.

Board fabrication itself — the KiCad designs and the gerber and outline files
generated from them — lives in the `hardware` repository and will move to its
own documentation site.
